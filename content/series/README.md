# 시리즈 포맷

시리즈마다 장면 구성, 길이, 고정 멘트를 정해 둔 틀. 대본(`/script`)은 반드시 해당 시리즈 포맷을 따른다.
같은 포맷이 반복돼야 시청자가 "아 그 시리즈"라고 알아보고 팔로우한다.

| 시리즈 | 코드 | 문서 | 상태 |
|---|---|---|---|
| Korean Secret | `items` | [korean-secret.md](korean-secret.md) | 🔴 작성 전 |
| Why Koreans…? | `explained` | [why-koreans.md](why-koreans.md) | 🔴 작성 전 |
| Seoul Survival | `tips` | [seoul-survival.md](seoul-survival.md) | 🔴 작성 전 |
| Ranked | `ranked` | [ranked.md](ranked.md) | 🔴 작성 전 |

새 시리즈나 수정은 `/series`로 한다. 틀은 [_TEMPLATE.md](_TEMPLATE.md).
