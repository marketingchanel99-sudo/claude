# 훅 템플릿 성적

`/review`가 매주 갱신한다. `/script`는 이 표를 보고 훅 후보를 고른다.

- **3초 유지율:** 영상을 3초 이상 본 비율. 유튜브는 쇼츠 분석의 "계속 시청함(Stayed to watch)" 비율, 틱톡은 영상 분석의 시청 유지 그래프 3초 지점 값, 인스타는 릴스 인사이트의 "초반 이탈" 지표를 쓴다.
- **평균 시청 비율:** 평균 시청 시간 ÷ 영상 길이
- 표본이 3개 미만인 템플릿은 판단하지 않는다 (`데이터 부족`).

| 훅 ID | 사용 횟수 | 3초 유지율 (평균) | 평균 시청 비율 | 저장률 | 판정 | 마지막 갱신 |
|---|---|---|---|---|---|---|
| `everyone-has-this` | 0 | - | - | - | 데이터 부족 | - |
| `why-koreans` | 0 | - | - | - | 데이터 부족 | - |
| `dont-do-this` | 0 | - | - | - | 데이터 부족 | - |
| `secret` | 0 | - | - | - | 데이터 부족 | - |
| `ranking` | 0 | - | - | - | 데이터 부족 | - |
| `whats-inside` | 0 | - | - | - | 데이터 부족 | - |
| `how-to` | 0 | - | - | - | 데이터 부족 | - |
| `price-shock` | 0 | - | - | - | 데이터 부족 | - |
| `vs` | 0 | - | - | - | 데이터 부족 | - |
| `pov` | 0 | - | - | - | 데이터 부족 | - |

판정 기준: 전체 평균보다 3초 유지율이 5%p 이상 높으면 `강함`, 5%p 이상 낮으면 `약함`, 그 사이는 `보통`.
