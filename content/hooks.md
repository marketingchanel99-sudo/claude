# 훅 템플릿

대본 첫 장면(0~3초)에 쓴다. `script.json`의 `hook_type`에 ID를 적어서 성과 분석에서 훅별 성적을 비교한다.

| ID | 템플릿 | 예시 |
|---|---|---|
| `everyone-has-this` | Every Korean has ___ | Every Korean has this in their bathroom. |
| `why-koreans` | Why do Koreans ___? | Why do Koreans never tip? |
| `dont-do-this` | Don't ___ in Korea | Don't do this on the Seoul subway. |
| `secret` | Koreans don't tell tourists this | Koreans don't tell tourists this about Olive Young. |
| `ranking` | I ranked ___ so you don't have to | I ranked every Korean convenience store snack. |
| `whats-inside` | What's inside a Korean ___'s ___ | What's inside a Korean office worker's bag? |
| `how-to` | How to ___ like a local | How to use T-money like a local. |
| `price-shock` | This costs ___ in Korea | This costs $3 in Korea. |
| `vs` | Korea vs ___: ___ | Korean vs American sunscreen. |
| `pov` | POV: you ___ in Seoul | POV: your first Korean sauna. |
