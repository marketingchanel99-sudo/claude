## 에피소드 폴더 규칙

```
episodes/2026-11-03-olive-young-sunscreen/
├── script.json      # 대본 (스키마: docs/script-schema.md). status 필드로 진행 상태 관리
├── shots.json       # Higgsfield 작업 ID와 결과 URL 기록 (재생성·재사용용)
├── assets/          # 장면 재료 (클립, 이미지, 음성)
└── final.mp4        # 최종 영상
```

에피소드 상태 흐름: `draft` → `approved` → `produced` → `published`

## 공통 규칙

- **언어:** 내레이션과 자막은 영어가 기본이다. 한국어는 "오늘의 한국어 한마디"와 화면 포인트로만 쓴다.
- **AI 공개:** 프로필에 AI 가상 크리에이터임을 밝히고, 모든 플랫폼에서 AI 생성 표시를 켠다. 지우는 "직접 써 봤다"고 말하지 않는다 (근거 기반으로만).
- **제휴 고지:** 제휴 링크가 있는 영상은 캡션에 고지 문구를 반드시 넣는다.
  - 영어: `As an affiliate, I earn from qualifying purchases.`
- **사실 확인:** 가격, 성분, 법·문화 관련 주장은 출처를 `script.json`의 `sources`에 남긴다. 리서치 단계(`/ideas`, `/products`)에서 근거가 없는 항목은 올리지 않는다.
- **크레딧:** [content/budget.md](../content/budget.md)를 따른다. 생성할 때마다 예상 비용을 보여주고 승인을 받는다.
